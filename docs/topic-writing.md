# 历史专题的写作与编辑

历史专题面向普通读者，以能够连续阅读的科普文章讲清一段历史或一个问题。每篇先确定范围和主线，再安排章节；人物、事件和地理材料围绕这条主线展开。小问题适合时收入主文，成为可以通过目录找到的章节。

## 选题与章节

优先从一件可核查的器物、一封书信、一趟行程或一次具体争议选题。先写清谁遇到了什么问题，再决定要讲多大一段历史。比较多个地方时，每个案例都要能回答同一个问题。文章围绕交通、生产、制度、信仰或知识之间的具体联系展开，历史事件作为深入案例，交代变化如何发生及不同人群的处境；器物也可成为跨地区解释的入口。相近的地区概览、制度或技术小题，应先考虑收入同一篇文章；中国史不按朝代逐段铺满目录，可以通过治理、社会变化或重大事件组织材料。丝绸之路与大航海各自成篇，分别讲清长期交流网络与跨洋扩张带来的变化。新增事件专题要有足以独立成文的问题和过程，避免把主文中的每个案例再次拆成文章。

合并文章时重新组织叙述，去除重复背景，补足前后关系。人物行旅、作品细读或制度案例可以占据连续多节，保留必要细节。跨地区专题交代各方自身的处境与行动；不把不同社会的变化拼成一条必然发展的道路。

篇幅由问题、材料与解释需要决定。复杂题材可以写成长文；每段应推进过程、解释条件、分析材料或呈现必要背景。不要用统一段落数、固定栏目、空泛结论或反复改写摘要来扩充篇幅。语言平实自然，具体说明谁做了什么、怎样做、遇到什么变化，不虚构对白、心理和现场。

正文应独立讲清关键过程。相关史事用于深入阅读人物、年代与出处，不能代替文章中必要的讲述。文章之间可以互相参照；交叉涉及同一事件时，按本篇问题选择详略。

## 来源与图文

事实、争议和不确定性遵循[事件写作约定](event-writing.md)与[数据维护](data.md)。现有文章和事件中资料充分的常见事实可直接据已有可靠材料重写；新增关键事实有疑点时再补查。保留原有出处与本轮实际复核是不同状态，不能因合并而改变来源的核验表述。

插图应解释正文中的对象、原理或结构，紧邻相关章节，并提供替代文字、图注和署名。真实图片核对许可与来源；原创示意图交代省略与适用范围。每个专题选一张能体现具体对象或核心关系的封面，正文按解释需要安排实物、史料或原创示意图，不为每节机械配图。博物馆图片同时保留对象年代与图像许可，避免把后世器物当作事件现场。

地理关系确实影响理解时，选择文中地图、路线图或主地图入口。有路线数据的专题在导言后列出路线与年代，读者展开总览即可查看各路线的空间关系；正文地图紧邻需要解释的章节，展示明确年代下的地域与事件位置。两者使用一致的地名和交互方式，避免为了重复同一信息另放一张图。地点较疏时直接标短地名，拥挤时按空间避让，完整名称与古今对照放在详情中。每张疆域图固定明确年代，说明近似地点和资料边界；跨时期路线总览不能当作同一年同时存在的交通网，示意路线不作为精确行迹。地图入口紧随相应段落，读者可按需展开、放大，关闭或收起后应保留正文位置；图中操作不得改变主地图的年份、筛选或相机。

## 内容维护

专题权威正文位于 `src/data/article-essays/`，按内容分文件维护；`article-groups.ts` 声明主文章与旧专题的对应关系，`articles.ts` 组装阅读数据。跨文章配图登记在 `article-media.ts`，按准确章节标题附着。配图需要紧跟某一段时，可填写该段在本节的下标，从零计数。博物馆图片原文件与公开许可清单分别放在 `public/images/articles/` 和 `data/article-images.json`。新文章可以独立声明分类、来源及可选的 `eventIds`，不需要先造一份旧导览；只有明确关联了史事才生成导览。章节的图片、地图和史事入口随文字位置生成，改稿后检查其对应关系。

调整选题或归并时，保留历次旧文章地址、旧标题搜索和可确认的事件已读记录。重写后的段落无法与旧段落可靠对应时，更新正文位置存储版本，不按相同下标冒充恢复；事件已读仍按稳定事件 ID 迁移。旧导览与来源保留为兼容输入，不把它们重新列成重复的主文章。
