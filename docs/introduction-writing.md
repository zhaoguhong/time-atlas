# 人物、政权与导读的编辑约定

介绍服务于普通读者在时间和地图中理解历史。逐篇选择重点、顺序和篇幅，不设统一字数，不以机械拆段或更换标题代替改写。事件正文另见[事件写作约定](event-writing.md)，日期、地理、来源与缓存要求见[数据维护](data.md)。

## 人物

开头交代身份及最值得理解的特点，正文通过具体经历、行动、作品或思想说明人物的变化。政治人物可以解释其选择与制度条件，文学艺术人物可以联系创作和生活，思想家需要把主张解释到读者能够理解。以上是选材角度，不是每篇必填的栏目。

资料有限时写有依据的短介绍，未知生卒、作品归属及关键争议继续保留。编辑过的介绍不等于完整传记，也不代表已经整理详细年谱。个人成就、同时代合作者和后世接受分别说明，不编造心理、对白或旅行。

正文不反复说明按钮、动画和资料收录方式。行迹证明、代表坐标与记录间空白等共通限制放在年谱状态和相关操作处；影响人物理解的争议仍随句交代。资料深度按编辑状态区分，不用字符数判定介绍是否完整。

基础身份导入快照保持原样；独立编写的短传放在 `src/data/catalog-reading-*.ts`，由 `catalog-reading.ts` 汇入最终人物记录。百科入口采用既有实体快照中 revision 相符的站点链接；保留出处不等于本轮重新抓取或核验。

## 朝代与政权

围绕政权怎样形成、依靠什么运转、后来怎样变化选择叙述线索。战争、制度、经济、社会生活与文化按各自的重要性展开，解释具体制度，不只罗列名词。不把所有政权排成同一种兴亡故事，也不把并立政权写成依次继承。

段落与标题由正文决定，可以连续叙述，也可采用能够概括实际内容的标题。短命政权和长期帝国不要求相同篇幅。存续年、导航分期及地图适用区间分别维护，纪年和边界限制在对应说明处保留。

## 专题、地点与年谱

专题导读要说明问题与章节之间的联系，让读者知道前一章怎样引出下一章；地图提示聚焦值得比较的地理条件，不重复事件全文。列表摘要继续简短，用来帮助选择阅读。

地点介绍写当地独有的历史条件与变化，配合出处；坐标与地名显示区间单独说明，不把古今城市范围视为完全相同。年谱节点讲清该时该地的实际活动，复杂背景链接到相关事件；任命和文学地名仍不能证明到访。

纯正文编辑进行必要数据检查与来源元数据审校，集中更新派生清单；渲染结构或界面行为改变时，再检查相关桌面与手机布局。不逐篇跑浏览器，不将结构检查表述为史实核验。
