# 架构与代码导航

山河纪是浏览器中的静态应用：React 与 TypeScript 管理界面和阅读状态，Vite 构建资源，MapLibre GL JS 绘制地图。历史内容和地图输入随仓库提供，运行时不依赖业务 API 或在线瓦片服务。

启动与验证见[贡献指南](../CONTRIBUTING.md)，来源、数据生成与审校见[数据维护](data.md)。本页说明当前模块职责与需要保留的行为，不记录历次实现过程。

## 状态边界

- 地图与时空柱共享历史年份和选中内容，分别保存时间筛选。`MAX_YEAR` 在公开构建中使用历史疆域切片上限 `TERRITORY_MAX_YEAR`（1912年），在预览中使用 `TRANSITION_MAX_YEAR`（1950年）。`PILLAR_MAX_YEAR`（2000年）和阅读分期与构建模式无关。搜索超出地图范围的事件自动进入时空柱，切换到地图时保留正文并显示地点参照。中外对照、中国和世界的地区选择属于时空柱偏好。
- 类别筛选由 `event-categories.ts` 统一处理，地图与时空柱沿用共享类别状态。一级选项包含原有大类和可交叉归属的细分主题；画布、阅读目录、自动浏览与 URL 解析使用相同语义，打开符合主题的事件不清空筛选。
- 时空柱的画布年份与跨度决定视野，探索起止年则筛选事件并限制自动浏览，两者不能混用。年份跳转、快速时期及“全部年代”调整画布视野；展开某类别的全部年代会解除时间筛选，再按现有地区与地点条件下的类别记录确定视野。
- 分享与返回需要保留对应的年份、阅读对象、筛选和专题状态。专题内部选章保留专题上下文；独立搜索可以退出专题。返回阅读时应恢复相应位置。
- 地图播放与时空柱自动浏览使用独立行为。时空柱交互会取消自动浏览；普通事件阅读保留当前画布时间，明确的“在地图中查看”使用事件日期。
- 拖动、滚轮和捏合跟随当前绘制的分数时间位置；年度标签与 URL 使用没有公元 0 年的整数纪年。松手不能让旧动画覆盖手势结果。
- 年谱逐条播放有出处的活动记录，同年多条与重复地点仍保留顺序。暂停保留播放进度；插值连线不代表历史道路或航线。当前行迹标签在狭窄地图中可移到锚点下方并贴合可用视口，避让地图说明与操作按钮，只移动阅读标签，不修改地理坐标。
- 全站昼夜模式与时空柱主题分别保存；原有四套主题由 `pillar-themes.css` 实现，留白、大事记、观测站由 `pillar-modern-themes.css` 实现，主题共享时间几何与卡片避让。连线与锚点仅为当前阅读事件渲染：自动浏览停留优先于手动选择，自动移动时不渲染；卡片高亮沿用同一个活动事件。尊重系统的减少动态效果偏好。

专题进度在本地存储中按稳定事件 ID 保存，读取时映射到当前章节顺序；旧版进度优先按最近阅读链接中的事件 ID 迁移，缺少事件 ID 时按当前目录映射旧章节下标；若检测到章节调序，仅保留能够确认的最后一章已读记录。最近专题继续阅读与专题直链刷新均优先定位指定事件，导读仍保留独立入口。旧版未记录事件 ID 的其他已读章节无法在调序后精确反推。

全局搜索匹配事件标题、别名、年代、地点、摘要、主题及明确关联人物的姓名、字与别名；优先显示直接名称命中，并说明人物、主题或介绍的命中线索。

1951—2000年的现代阅读使用独立的20世纪导航分段。分享链接按 `visual` 验证对应时间域。地图链接遵循当前构建的地图上限，时空柱链接可保留到2000年。

年份对比按参考年份的实际覆盖提示疆域轮廓或地点资料。中国史和中外对照在近现代地点图的两端显示台湾、澎湖的年末状态。

时空柱中的专题章节在阅读面板保留上一章、下一章／完成旅程和退出入口，导读页也可退出。进入1950年后的章节时沿用同一专题状态与章节跳转逻辑。

## 加载与构建

地图由 `data/map-packs/` 离线还原到运行目录；浏览器按年代请求 GeoJSON 切片并使用有界缓存，不下载整个历史归档。`mapTerritorySlice` 为主地图、对照和文中地图共用，地点地图年份始终返回空疆域，并按需加载小型岛屿陆地资源。地图画布像素倍率上限为2，瓦片缓存上限为32，避免高像素密度设备分配过大的绘图缓冲。数据准备命令与来源校验见[数据维护](data.md#仓库无损压缩与运行数据)。

事件和人物的目录包含摘要、日期与检索字段，使用紧凑列存储，在浏览器中还原为记录；开发时完整正文及来源通过生成的 JSON 按需加载；生产时正文与来源嵌入对应静态 HTML，交互应用复用该数据，不再额外发布一套正文 JSON。独立阅读页转入地图时直接复用当前 HTML 的记录，其他记录才请求对应页面。正文缓存按最近使用保留最多20篇。时期概览与地点档案的聚合出处使用独立的来源索引，首次打开相关页面时请求，失败可重试；引用列表保留来源备注。请求去重与缓存由阅读 hook 管理，正文与来源索引请求限时20秒，地图切片请求限时30秒，限时包含响应正文的读取。失败时保留摘要、已有资料和重试入口。画布模块失败时保留阅读内容，点击“重新加载画布”会重开当前交互工作区。生成链路与原始内容入口见[阅读目录与正文](data.md#阅读目录与正文)。

MapLibre worker 由 `HistoryMap.tsx` 显式导入 `maplibre-gl-worker.mjs?worker&url`，[`vite.config.ts`](../vite.config.ts) 使用 ESM worker 输出。修改这条链路时，开发服务可用不足以证明生产包可用，必须运行生产预览检查。

## 布局与回归重点

地图的时期导航位于时间轴。桌面横排显示各时期，窄屏使用下拉选择；中国分期列至近现代。点击左端年份可输入具体年代。地图滑轨只覆盖可显示的地图年份。“跳转年份”接受整个阅读范围，超出地图上限的新年份及时期导航打开时空柱。在含近现代地点地图的版本中，清末滑轨右端可直接进入1913年，再沿滑轨选择至1950年。到达整个地图的年份上限时，右端入口打开之后的时空柱年份。超出地图年代范围的选中事件，在地图画布上方保留独立于阅读面板的年代说明。时空柱画布延伸到底部，不为工具预留底栏或缩短邻近卡片。右下角半透明按钮直接覆盖画布：桌面为放大、缩小与设置，手机只显示设置。打开设置会停止自动浏览。

设置顶部依次放置浏览方式、中外对照或世界模式下的世界地区、事件类别与结果及清除筛选入口，其后为“当前范围事件”目录。年份跳转、快速时期（含全部年代）和起止年筛选收在“年份与时期”中；点击画布中央年份会展开该组并聚焦年份输入框。自动浏览、外观与简介依次折叠，底部保留操作说明及按需出现的恢复阅读入口。目录按钮显示当前时间范围内的全部记录数，打开后说明实际排布节点数，并可筛选起点已移出视野、仍在延续的记录。手机两行标题的高度参与卡片排布，悬浮工具不参与排布；不能因卡片排布而丢失范围内事件的阅读入口。只有实际放入一张卡片时，才更新其余候选与最近卡片的距离并重排。空状态恢复按全年代筛选结果决定扩展时间或解除筛选。丝路示意线属于对应专题，不是默认常驻图层。

推荐阅读优先使用人工标注的关系，再按共同人物、同地区同名地点和具体主题给出阅读线索。共同人物只表达已有事件关联，同地点只表达阅读参照；政治、战争等宽泛分类不单独构成主题关系，不由先后顺序推断因果。事件页按明确的专题章节成员关系显示阅读路径入口，进入时保持当前事件并定位对应章节，不通过关键词推断入选专题；当前专题继续使用原有的章节导航。

地图事件短标签沿用事件的年代文字，保留“约”“至迟”“起”等限定语。跨地区的年代对照仅在两条记录都明确到同一年时显示“同年对照”。两条有起止年份的记录覆盖区间相交时显示“年代范围重叠”。其他接近的记录显示“相近年代”。

地点目录、地点档案、事件详情中的地点入口及探索筛选统一调用 `eventAtPlace`。事件提供 `placeIds` 时使用明确关联（包括刻意排除城市归属的空数组），旧记录再回退至地名匹配；完整正文与轻量阅读目录都保留该字段。一个事件可以同时进入多个城市档案，代表坐标仍只有一处；地点关联不改变地图疆域或人物年谱。

人物、事件、朝代、世界政权和地点分别以 `/people/:slug/`、`/events/:slug/`、`/dynasties/:slug/`、`/polities/:slug/`、`/places/:slug/` 为阅读地址，`record-url.ts` 通过生成映射解析稳定记录 ID。选择记录后地址栏与分享链接只保留路径；地图、筛选、年谱与专题章节状态保留在浏览器历史和当前标签页，匹配的记录刷新时恢复。直接访问链接优先显示指定记录，旧档案 hash 不再作为公开入口。`use-record-position.ts` 在地图侧栏的完整正文加载后恢复本机阅读位置；轻量阅读页单独保存文档滚动位置，进入地图前保存，关闭地图后恢复。档案目录提供普通 HTML 链接，阅读卡片保留真实 `href`，支持新标签页打开。`seo.ts` 为静态页面和客户端提供一致的面包屑结构化数据；切换记录时同步更新标题、摘要、规范地址与结构化数据。地图中的原始疆域记录仍保留来源适用区间，并链接到已编写的政权档案，不将原始图层批量伪装成历史正文。

直接访问主域名使用默认地图年份与筛选，不自动打开上次内容。首页的“继续上次阅读”从当前浏览器的最近阅读记录取一项有效独立地址；点击后才恢复阅读。深浅色、收藏与阅读进度继续保留。浏览器前进后退仍恢复对应快照。

专题文章使用独立的 `articleId`，打开文章不改变当前年份、筛选、视图或相机，也不自动选择事件。主地图与时空柱在文章／目录阅读期间不挂载；返回时以保存的最新相机和观察状态恢复。`/topics/:slug/` 是文章地址，`/topics/` 是目录地址；公开短名称由 `data/article-slugs.ts` 独立映射到内部文章 ID，不解析旧路径。目录与文章地址不携带地图参数；浏览状态在 React 与浏览器历史中保留，当前标签页的 `sessionStorage` 保存刷新所需的地图参数，仅在匹配路径的刷新时恢复，新打开的分享链接不继承该状态。构建后的 HTML 包含完整正文、来源、独立元信息和规范地址；交互阅读界面加载时，沿用读者在静态正文中已到达的段落和段内位置；尚未滚动时恢复本机保存的阅读位置。`scripts/build-pages.mjs` 从同一文章数据生成静态页面与站点地图，避免另维护一份正文。`prepare-reading.mjs` 同时生成 `article-runtime.json`，提前完成专题归并；运行端只保留当前文章、导览与旧已读记录需要的事件成员关系，不加载编写时期的旧正文和组装逻辑。导航快照与最近阅读分别保留文章和事件导览的身份。

读者主动打开专题地图一览时，按明确关联的导览地点聚焦地图，进入史事后改为聚焦相邻地点；丝路保留专用范围。世界史专题不能一律套用中国视野，现代史事仍遵守地图与阅读年代分离的规则。

事件等资料在桌面使用侧边阅读区，手机竖屏使用底部面板，短横屏使用左右分栏。专题目录与文章使用铺满主区域的阅读布局，暂时隐藏画布、时间轴与资料面板工具；点击地图或时空柱顶栏入口恢复原视图。修改布局时检查触控目标、键盘焦点、卡片裁切、阅读滚动、旋转和实际可点击区域。测试不能为了选中被裁切的卡片而绕过真实交互条件。

动画中断需验证中间位置、取消后的稳定状态以及 BCE/CE 边界；自动浏览需分别验证停留、移动和取消。真实绘制帧测试与受控时钟测试各有用途：前者验证可见运动，后者固定特定阶段进行交互。不要用一次瞬时属性轮询代替整个运动过程的验证。

目录封面与文中实物图由 `article-media.ts` 按文章和章节标题组织；`data/article-images.json` 保留博物馆对象、许可、下载地址、尺寸和文件哈希。封面引用文中已注明出处的同一图片，浏览器只加载随站点分发的资源。

`TopicDirectory.tsx` 在图文首页展示侨批、漕粮和经度三个阅读入口，提供搜索与卡片／列表／分类目录三种展示。手机用下拉框选择分类，卡片以缩略图配标题和简介排列，通过 `lib/topic-directory.ts` 保存目录偏好，并按实际文章文字估算阅读时间。筛选只影响专题目录，不修改地图、时空柱或事件类别。

`TopicPanel.tsx` 阅读 `ReadingArticle`，按实际内容生成目录、小节、插图、可选史事与来源。`article-groups.ts` 定义主文与旧专题的对应关系；`articles.ts` 合并明确关联的事件并按年代形成主文导览，旧导览与前次归并的完整史事集合继续供明确事件链接和已读迁移使用。`article-migration.ts` 按事件 ID 合并已读记录，并归并收藏与最近阅读；旧标题仍参与搜索。文章没有关联事件时不显示事件区，没有地理探索设置时不显示地图一览。`use-topic-position.ts` 按文章保存当前可见段落及段内比例，进入地图、重开文章或刷新后恢复；重组后的正文使用 v6 位置键。旧版段落下标只对当时的正文有效。屏幕旋转继续由 `useReadingResize` 保持可见内容，并排除悬浮目录。正文位置与史事的手动已读标记分别保存。文章收藏使用既有书签中的 `topic:` 键。

`lib/topic-reading-presentation.ts` 将段旁事件按段落归入“延伸阅读”，使用事件标题并在组内去重。次要案例只有在完整索引保留相同事件 ID 时才移出段旁；这里不修改正文和导览数据。文末史事用原生 `details` 默认收起，继续阅读入口与已读进度保留在折叠区外；展开状态按文章保存在 sessionStorage，存储不可用时仍可操作。目录跳转到史事区会主动展开；摘要和各事件行提供独立的位置锚点，刷新与返回可以恢复到索引中的具体一行。路线入口明确标注所含路线，内嵌地图显示对应年份。

`ArticleMapFigure.tsx` 在读者主动展开后才懒加载 `TopicInlineMap.tsx`；章节地图离开阅读视口附近、收起或离开文章时释放画布和进行中的请求。放大的地图在对话框关闭前保持挂载。图的占位保留标题、年份与说明，避免加载前没有内容；正文地图可放大到原生模态对话框，保留本图相机与选中内容，关闭后恢复正文位置和放大按钮焦点。原位与放大视图使用同一地图实例，不同时创建两个 WebGL 画布。它按图的明确年份复用历史切片与 `activeMapFeatures` 展示规则，现代海岸河流作参照，使用有界缓存与30秒加载／绘制超时；失败保留正文、图注和重试入口。内嵌图的相机、选中地点和政权全部是局部状态，不写主地图、全站年份、URL或阅读进度。1913—1950年的内嵌图显示地点与海岸参照，1950年后的图保留事件地点并标注地图年份。内嵌图同样保留显式 ESM worker 导入。航线颜色、名称与年代始终可见，详细路线说明与出处在图下按需展开。航线复用有来源的 `topicRouteById`，在日界线切开为单世界线段；地理参照点不冒充历史事件。全球图按明确 bounds 适配窄屏，重置视野使用相同边界。地图容器的定位与高度使用明确的父子选择器，避免被 MapLibre 的默认相对定位覆盖。

有路线数据的专题由 `ArticleRouteFigure.tsx` 在导言后展示路线名称、图例与说明，读者展开或放大时才加载交互地图；原位画布离开阅读视口附近时释放。`RouteMap.tsx` 供总览和 `TopicRouteReader.tsx` 共用，底图只使用 Natural Earth 地理轮廓，不加载历史政权，与按年份解释政权和事件位置的正文地图分工不同。图上短地名按实际空间避让其他名称、地点和控件；编号辅助对应逐站列表，详细古今地名保留在列表和站点详情中。放大按钮打开首条路线，点击图例或地图地点则打开对应路线或站点。放大时原位保留等高占位、释放总览画布，关闭后恢复总览和触发入口焦点。读者可以查看全程、选择地点或逐站切换，镜头移动遵守减少动态效果偏好；不使用自动计时推进。路线和站点选择不改变全局年份、主地图视野、章节进度或 URL。`lib/topic-routes.ts` 连续展开经度，避免环球航线跨日界线时反向横穿地图。地图或 WebGL 失败时仍保留行程文字、出处与重试入口。

文章中的路线总览和章节地图使用协作手势：普通滚动和触屏单指滑动留给文章，触控板双指捏合、触屏双指捏合与带修饰键的滚轮用于地图缩放。原位地图仍须启用 `scrollZoom`，因为浏览器将触控板捏合传为 Ctrl 加滚轮事件；不能用禁用整个处理器的方式避免抢走文章滚动。放大视图允许直接拖动与滚动缩放，所有操作继续保持局部状态。

地图、时空柱与历史专题共用一套顶部按钮样式。两个视图入口靠近排列，当前视图以底色标记。历史专题稍作间隔，打开专题时显示描边，点击地图或时空柱时清除专题入口标记，阅读内容按原有视图切换规则处理。

移动端顶部采用单行布局，山河纪文字站名、地图、时空柱、历史专题、搜索与更多操作始终并排。紧凑布局省略站标和英文副标题，宽度不超过420px时统一隐藏三个导航图标。入口保留文字和至少44px的操作高度，320px窄屏进一步缩减间距。搜索框在顶部原行内展开，覆盖导航并提供取消入口，结果列表在顶栏下方展开。白天／夜间模式收进更多菜单。独立文章入口和完整应用从同一处加载顶栏样式。窄屏文章把返回、收藏、分享和目录放在同一行，目录在原地展开。专题目录与文章收起底部时间轴并释放阅读空间，进入具体史事后恢复章节与播放控制。

## 独立阅读入口

`main.tsx` 是轻量入口。打开或刷新人物、事件、朝代、世界政权、地点及其目录时，保留构建时生成的 HTML，只加载 `reader.ts` 与共享阅读样式。正文不依赖 React、全量目录或地图引擎。收藏、分享、目录筛选、主题和阅读位置由原生交互增强。独立事件页在构建时使用地图侧栏共用的 `relatedReading` 生成续读链接、日期与关联说明。点击“在地图中查看”会加载 `app-entry.tsx`，当前条目有匹配的浏览器历史状态时会恢复探索视图。点击“专注阅读 · 关闭地图”会替换当前文档，回到轻量阅读页。工作区内的事件切换复用当前应用。

首页仍直接进入地图探索。专题直达页保留带正文和目录的静态 HTML，由 `topic-entry.tsx` 复用 `TopicPanel`，启用目录跳转、插图放大、收藏和阅读进度。静态页只提供当前专题的图文数据、图中史事摘要、路线图例和用于迁移旧进度的章节索引；全站事件与人物目录随 `app-entry.tsx` 按需加载。展开章节地图或路线图时，按需加载地图代码、样式、路线坐标和地理数据。读者进入相关史事时启用全站阅读，主画布继续收起；主动进入地图、时空柱或专题地点一览后才挂载主画布。全站搜索也在读者输入后启用。

画布是否启用随浏览器历史快照恢复。轻量页和交互页共用规范地址，地图上下文只存在当前标签页与浏览器历史中。HTML 中的档案正文数据仅包含目录没有的字段，并转义脚本结束标记；客户端将其与目录合并后校验记录 ID 和来源字段。章节地图由 MapLibre worker 加载海岸、湖泊和河流，页面线程只解析并缓存用于按年筛选的历史疆域切片。
