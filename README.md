# 山河纪 · Time Atlas

**在地图上读历史，在时间中看山河。**

山河纪是一个开源历史网站。沿时间轴看疆域变化，点开地图上的事件读它的来龙去脉，或切换到时空柱，对照同一时期的中国与世界。

## 可以怎样探索

- **地图**可跳转年份、播放年代或对比两个年份的疆域。点击事件或政权，可以继续查阅人物、地点和出处。
- **时空柱**把中外事件放在同一条时间轴两侧。可按地区、类别和年代筛选，也可让画布按收录事件自动向后浏览。
- **历史专题**从一件器物、一封信或一条路线读起。可以跟着侨批看一笔跨海汇款，沿运河看漕粮进京，或从航海钟了解怎样确定海上经度。郑和下西洋、玄奘西行等专题章节可逐站查看路线。
- **人物年谱**可以跟随苏轼、康熙、诸葛亮等人的已核对活动记录，按年代逐站浏览。

可以按人物及别名、事件、地点和主题搜索。档案与专题都有独立分享网址，地图链接可保存当前视角。收藏与阅读进度保存在当前浏览器，首页可继续上次阅读。

## 地图与时空柱

### 地图：事件发生在哪里

在左下角的“地图图层”控制历史事件、城市与都城、政权图层。想限定事件所在区域时，在列表里选“只看当前地图范围”。移动地图后，可从“地点与时间段”重新选取范围。

地图与时空柱共享选中事件，各自记住时间筛选。在线地图可浏览至 1912 年。点击底栏年份旁的下拉箭头，可输入到 2000 年，输入 1913 年及之后的年份会打开时空柱。也可以点时期栏的“近现代”，或从滑轨右端的“后续史事”进入时空柱。切换到地图时会标明所用地图的年份。

### 时空柱：同一时期发生了什么

在顶栏切换到“时空柱”。中外对照时，左边是中国之外的历史，右边是中国历史。右下角的“设置”可以切换中外对照、中国或世界，筛选地区及事件类别。

| 操作                   | 方法                                                                                |
| ---------------------- | ----------------------------------------------------------------------------------- |
| 移动年代               | 上下拖动或滚轮滚动                                                                  |
| 缩放时间范围           | 手机双指捏合；桌面 Ctrl / ⌘ 加滚轮，或点击 ＋ / −                                   |
| 跳转年份               | 点击画布中央年份，或展开设置 → 年份与时期                                           |
| 找到当前范围的全部事件 | 设置 → 当前范围事件，支持搜索、阅读与范围定位                                       |
| 自动向后浏览           | 设置 → 自动浏览与停留，可选每站停留 4、6 或 10 秒，拖动或打开事件即停止             |
| 更换外观               | 设置 → 外观与简介，可选琉璃时柱、素笺编年、山河长卷、经纬织带、留白、大事记、观测站 |

画布放不下的事件仍可在“当前范围事件”中查找。想看整个时期，可在“年份与时期”展开画布。想筛选事件并限定自动浏览，则设置起止年。画布获得键盘焦点后，可用方向键、加减键和 Home / End 操作。

### 手机阅读与显示

打开人物、事件、朝代、世界政权或地点的独立网址时，先显示正文，点“在地图中查看”再打开交互地图。手机竖屏在底部显示事件资料，横屏可同时查看左侧地图与右侧资料。

专题目录支持搜索、分类和三种展示方式。读文章时，可从“文章目录”跳到小节，放大插图，或按需展开文中的交互地图。点进“延伸阅读”的史事后，可以通过“专题导读与目录”回到原文。文中地图的操作只作用于当前插图，返回主地图时可接着原来的年份和视角浏览。

手机在“更多操作”中切换昼夜模式、进入专注模式或全屏，也可按浏览器提示添加到主屏幕。添加后仍需联网加载内容。

## 本地运行

需要 **Node.js 22.12+**，推荐 Node.js 24；仓库提供 `.nvmrc`。日常开发无需 Python、业务后端、数据库、地图 API Key 或在线瓦片服务。

下载仓库后，在项目目录运行以下命令。

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://127.0.0.1:5173`。运行所需地图包和人物数据随仓库提供；开发、测试和构建命令会自动准备派生文件，无需额外下载历史资料。

用以下命令构建并预览与在线地图范围一致的静态网站。

```sh
npm run build:public
npm run preview
```

`dist/` 是完整的静态网站，须通过 HTTP/HTTPS 访问。子目录部署与自定义域名说明见[静态托管](CONTRIBUTING.md#静态托管)。

## 数据来源与边界

| 内容             | 来源与使用方式                                                                                                                                  |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 历史疆域         | Cliopatria / Seshat（CC BY 4.0）。取固定版本的政权记录，保留原始名称和年代，简化边界后按时期打包。[版本与处理记录](public/data/provenance.json) |
| 现代自然地理参照 | Natural Earth 的公有领域数据，用于展示陆地、海岸、河流和湖泊。                                                                                  |
| 人物基础身份     | Wikidata 的 CC0 结构化数据，用于姓名、别名及有记录的生卒年等基础信息。[实体与版本清单](data/people.sources.json)                                |
| 历史讲解与年谱   | 山河纪编写中文讲解，逐条标明原典、博物馆或研究文献等出处。                                                                                      |
| 专题文物照片     | 大都会艺术博物馆 Open Access 的 CC0 图片，逐张保留藏品链接、馆方署名和许可。[图片来源清单](data/article-images.json)                            |

仓库随附运行所需的地图包、人物数据、配图和来源记录。网站提供按需加载的地图切片、原创讲解和公开来源索引。下载的参考文章和原始网页快照留在本地供核对。中国历代人物传记资料库（CBDB）的学术版仅作研究参考，整库由原项目提供。[地图包](data/map-packs/) · [第三方声明](THIRD_PARTY_NOTICES.md) · [文件与公开范围](CONTRIBUTING.md#文件与公开范围)

各地区和时代的收录深度有差异。地图空白表示缺少来源支持的疆域数据。事件坐标有时指向整个区域。

- 历史上没有公元 0 年；早期遗址使用约略年代和考古区间。
- 导航时期是学习分段，不等同于政权实际存续日期。
- 人物年谱仅纳入有独立出处可核对的活动记录。

参考资料保留来源备注，包括尚待核对的引用入口；提供链接、成功留存网页和人工核对对应内容是不同状态。

地图名称的调整、疆域筛选及来源核对方法见[数据处理与维护](docs/data.md)。
