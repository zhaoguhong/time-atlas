# 山河纪 · Time Atlas

**在地图上读历史，在时间中看山河。**

山河纪是一个开源历史探索网站，把历史事件、人物和地理位置放在一起：沿时间轴观察政权疆域，点击事件阅读来龙去脉，也可以在“时空柱”中对照同一时期的中国与世界。

## 可以怎样探索

- **沿地图看历史**：拖动时间轴、播放或直接跳转年份，观察政权疆域变化，对比两个年份的版图。
- **对照中外大事**：切换到时空柱，把中国与世界历史放在同一条时间轴两侧，缩放查看更长时段或更细的事件。
- **从事件读到人物**：阅读事件背景、经过、影响，以及相关人物、朝代与政权档案和参考出处。
- **跟随专题与年谱**：按章节探索三国、丝绸之路、大运河、宋代社会等专题；跟随苏轼、康熙、诸葛亮已核对的活动记录逐站浏览地图。
- **找到并留下阅读线索**：搜索人物、别名、事件与地点，按年代和类别筛选；收藏、继续最近阅读，或分享当前视图。

支持电脑和手机，提供日间与夜间模式。收藏和阅读进度保存在当前浏览器中，分享链接保留阅读与视图状态。

## 地图与时空柱

### 地图：事件发生在哪里

底部时间轴可切换时期、输入年份和播放年代；“年份对比”用于观察两个年份的疆域差异。左下角“地图图层”控制历史事件、城市与都城、政权图层的显示。点击事件或政权可打开右侧资料，在人物、地点与参考来源之间继续阅读。

地图统一浏览中外历史，时空柱的中国／世界及地区筛选不会限制地图内容。两种视图共享年份与选中事件，并分别记住时间筛选。

### 时空柱：同一时期发生了什么

顶栏切换到“时空柱”。中外对照时，左侧是中国之外的历史，右侧是中国历史；也可在右下角齿轮设置中选择仅中国、仅世界或具体世界地区。

| 操作                   | 方法                                                              |
| ---------------------- | ----------------------------------------------------------------- |
| 移动年代               | 上下拖动或滚轮滚动                                                |
| 缩放时间范围           | 双指捏合、Ctrl / ⌘ 加滚轮，或点击 ＋ / −                          |
| 跳转年份               | 点击画布中央年份，或在设置中选择年份与时期                        |
| 找到当前范围的全部事件 | 设置 → 全部事件，支持搜索、阅读与范围定位                         |
| 自动向后浏览           | 设置 → 自动浏览，可选每站停留 4、6 或 10 秒；拖动或打开事件即停止 |
| 更换外观               | 设置 → 外观与简介，可选琉璃时柱、素笺编年、山河长卷、经纬织带     |

画布根据时间范围与可用空间展示事件；未展开的事件仍可通过“全部事件”查找。跨度较长的过程在起点移出画布后，可通过“延续中的记录”阅读。自动浏览按当前筛选推进，结束后不循环。

画布获得键盘焦点后，可用上下方向键、加减键和 Home / End 操作。右上角太阳／月亮控制全站昼夜模式，与时空柱样式独立保存；系统启用“减少动态效果”时关闭进场和过渡动画。

### 手机阅读与显示

手机竖屏使用底部阅读面板，横屏使用左地图、右资料布局。右上角“更多操作”可打开最近阅读与收藏、来源、分享，以及以下显示选项：

- **进入专注模式**：收起顶部导航，保留画布、阅读和时间轴。
- **全屏浏览**：在浏览器支持时隐藏浏览器界面。
- **添加到主屏幕**：按浏览器提示或操作说明安装，仍需联网加载内容。

旋转屏幕或切换显示方式会保留当前年份与阅读内容；全屏和安装能力取决于浏览器。

## 内容覆盖

时间范围约为**公元前 10000 年至公元 1912 年**，以中国历史为主要阅读内容，并收录世界史重要节点。

| 内容           | 当前收录                                            |
| -------------- | --------------------------------------------------- |
| 历史事件       | 643 个，其中中国之外的事件 198 个                   |
| 人物           | 673 位，其中 280 份有编辑介绍、393 份为基础身份记录 |
| 朝代与政权档案 | 中国 53 个、世界 55 个                              |
| 历史专题       | 13 个，共 97 章                                     |
| 已核对活动年谱 | 苏轼、康熙、诸葛亮，共 52 条活动记录                |

统计依据为 2026-10-23 生成的[覆盖清单](public/data/coverage.json)。基础身份记录不等同于完整传记，活动年谱动画只表达记录先后，不推断真实道路。内容仍在持续补充，并非完整的世界通史。

## 本地运行

需要 **Node.js 22.12+**，推荐 Node.js 24；仓库提供 `.nvmrc`。日常开发无需 Python、业务后端、数据库、地图 API Key 或在线瓦片服务。

下载仓库后，在项目目录运行：

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://127.0.0.1:5173`。运行所需地图包和人物数据随仓库提供；开发、测试和构建命令会自动准备派生文件，无需额外下载历史资料。

生产构建与本地预览：

```sh
npm run build
npm run preview
```

`dist/` 是完整的静态网站，须通过 HTTP/HTTPS 访问。子目录部署与自定义域名说明见[静态托管](CONTRIBUTING.md#静态托管)。

## 数据来源与边界

| 内容             | 来源与使用方式                                                 |
| ---------------- | -------------------------------------------------------------- |
| 历史疆域         | Cliopatria / Seshat，固定源版本并简化几何，保留 CC BY 4.0 署名 |
| 现代自然地理参照 | Natural Earth，公有领域数据                                    |
| 人物基础身份     | Wikidata，CC0，保留实体版本与引用                              |
| 历史讲解与年谱   | 项目整理的中文摘要，逐条提供原典、博物馆及研究机构等出处       |

地图提供来源支持的全球历史疆域轮廓，事件与人物阅读仍以中国及周边为主。**这是持续完善的历史学习项目，资料并不完整，也不代表全部史实已获专家认证。**

- 历史上没有公元 0 年；早期遗址使用约略年代和考古区间。
- 导航时期是学习分段，不等同于政权实际存续日期。
- 缺失疆域保持空白，不以相邻年份猜测填补；空白不表示当地无人居住。
- 现代海岸与河流仅作参照；事件坐标可能代表一个区域。
- 人物与事件相关，不代表本人到访；只有独立核对的活动记录进入年谱。

详见 [数据处理与维护](docs/data.md) 和 [第三方署名及许可](THIRD_PARTY_NOTICES.md)。
